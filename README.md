# Meet6

Meet6, 6 kisilik canli tanisma odalari uzerine kurulu bir Flutter uygulamasidir.

## Konsept
- 6 kisi ayni odada bulusur.
- 15 dakika serbest grup sohbeti yapilir.
- Son 1 dakikada sistem +5 dakika uzatma oylamasi sorar.
- Sohbet sonunda herkes gizlice 1 kisi secer.
- Karsilikli secim olursa ozel sohbet acilir.

## Canli onizleme
GitHub Pages: https://queensho.github.io/Meet6/

`main` branch'e gelen her degisiklik GitHub Actions ile otomatik olarak Flutter Web'e build edilip GitHub Pages'e yayinlanir.
